⚙️ Pengaturan Spreadsheet

Kosongkan untuk menggunakan data demo lokal.

Langkah Menghubungkan:

  1. Buka Google Sheets → Ekstensi → Apps Script.
  2. Tempel kode dari file Code.gs.
  3. Pilih fungsi setupDatabase lalu klik Run.
  4. Klik Deploy → New deployment → Web app.
  5. Akses: Anyone • Eksekusi: Me.
  6. Salin Web App URL dan tempelkan di atas.
